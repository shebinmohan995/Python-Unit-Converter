Python Unit Converter

A simple Python project that converts values between different units of length, weight, and speed.

Features

- Length Conversion: Metres (m), kilometres (km), centimetres (cm), and millimetres (mm).
- Weight Conversion: Kilograms (kg), grams (g), milligrams (mg), pounds (lbs), and ounces (oz).
- Speed Conversion: Metres per second (m/s), kilometres per hour (km/h), miles per hour (mph), and feet per second (ft/s).
- User-friendly input prompts.
- Conversion results displayed in the terminal.

How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python unit_converter.py
